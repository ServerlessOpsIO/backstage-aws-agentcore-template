# Stage: context

**Aim**: agree what is being decided, what the decision must achieve, and what limits it.

## What to establish

Ask one question at a time, in roughly this order. Skip a question the participants have
already answered.

1. What has to be decided, in a sentence, and why now?
2. What must the decision achieve?
3. What limits it: time, money, people, existing systems, rules?
4. What is being taken as given?

## Recording

- Use the `add_context` tool with kind `goal` for each thing the decision must achieve,
  `constraint` for each limit, and `assumption` for each thing taken as given.
- Record each in the participant's words, shortened if need be.

## Before closing the stage

- Read the context back in a few lines.
- If something that plainly bears on the decision has not been mentioned, one hint is
  allowed in this stage (see Hints).
- Then call `complete_stage`.
