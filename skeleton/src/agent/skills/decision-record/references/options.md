# Stage: options

**Aim**: the participants set out the options, and what counts for and against each.

## What to establish

1. Ask what options there are. Record each with the `add_option` tool as it is named.
2. When nobody has more to add, ask whether doing nothing is an option. Record it only if
   a participant says it is.
3. Take the options one at a time. For each, ask what counts for it and what counts
   against it, measured against the goals and constraints in the record.

DO NOT propose an option, and DO NOT give an advantage or a drawback of your own. Asked
for one, ask which goal or constraint the participants think the option serves worst.

## Recording

- `add_option` for each option. Change its name or description with `update_option`.
- `add_tradeoff` for each advantage or drawback, with the option's identifier.

## Before closing the stage

- Read back each option with its advantages and drawbacks, by identifier.
- If an option has nothing recorded against it, or nothing for it, one hint about that
  option is allowed: point at the goal or constraint nobody has measured it against.
- Then call `complete_stage`.
